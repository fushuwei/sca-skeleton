   模版引擎了，但是你要考虑到实际生产环境中需要再登录加载一些基础配置信息，比如 logo、系统名称、版权信息等，考虑到这些场景或者其他的实际场景，是直接使用
   js 做 ajax 请求获取到这些信息，还是使用 thymeleaf 模版赋值？哪个才是企业级生产最佳实践？请你认真仔细思考并给出合理的选择。
