# 问题清单

## 问题描述

1. /auth/logout 接口地址要求经过认证，未登录不允许访问

2. /auth/logout 接口要求在 HttpOnly Cookie 中携带 刷新 Token

3. 前后台的 OAuthCallbackView.vue 页面, 登录成功跳转时不要出现正在跳转的文字, 改成全局 loading 效果，建议在前端共享模块写一个全局 loading 效果的 UI 组件，我之前已经提供了 loading 效果，不需要你重新写一个效果

4. 前后台点击退出, 都跳转到了 http://192.168.1.106:9001/login/admin?logout ，这个是有严重问题的，因为9001是 auth 服务的端口，不是网关

5. 点击 admin 后台的退出按钮, 访问 http://localhost:9999/auth/logout 接口, 但是在 chrome 的网络中, 可以在全部里面找到, 但是在 Fetch/XHR 里面竟然没有, 不知道为什么

6. 关于登录过程存在的一个体验问题（以后台 admin 页面为例）：访问 localhost:5173，浏览器跳转到 auth 的登录页，当在这个登录页停留一段时间，然后输入正确的用户名和密码，点击登录后，页面没有任何提示，浏览器会刷新，但是刷新后依旧停留在登录页


## 处理要求
