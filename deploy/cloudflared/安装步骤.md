# Cloudflared Tunnel 完整安装步骤

**服务器：** 192.168.1.105 (Ubuntu Server)
**域名：** newease.cloud
**前置条件：**
- 已安装 mihomo (Clash) 代理服务
- mihomo 配置了 SOCKS5 端口（默认 7891）
- 在阿里云已购买域名 newease.cloud

---

## 第 1 步：安装 cloudflared

```bash
# 下载最新版
wget https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb

# 执行安装
sudo dpkg -i cloudflared-linux-amd64.deb

# 验证版本
cloudflared --version
```

---

## 第 2 步：登录 Cloudflare 授权

```bash
cloudflared tunnel login
```

执行后会生成 URL，在浏览器访问并授权：

1. 打开终端显示的 URL（如 https://dashboard.cloudflare.com/...）
2. 登录 Cloudflare 账号
3. 选择 newease.cloud 域名
4. 授权成功后，会在 /root/.cloudflared/ 生成 cert.pem

---

## 第 3 步：创建隧道

```bash
cloudflared tunnel create thinkpad-tunnel
```

**记下返回的 Tunnel ID (UUID)**，后续配置需要使用。

示例输出：
```
Created tunnel thinkpad-tunnel with id 1c1383ed-a3a6-44ed-979d-e4662cff94fd
```

---

## 第 4 步：创建隧道配置文件

创建 /etc/cloudflared/config.yml：

```yaml
tunnel: 1c1383ed-a3a6-44ed-979d-e4662cff94fd
credentials-file: /root/.cloudflared/1c1383ed-a3a6-44ed-979d-e4662cff94fd.json
protocol: http2
loglevel: warn

ingress:
    # 1. SSH 远程访问：ssh.newease.cloud -> 22 端口
    - hostname: ssh.newease.cloud
      service: ssh://localhost:22

    # 2. 项目 sca-skeleton：newease.cloud -> 8080 端口
    - hostname: newease.cloud
      service: http://localhost:8080

    # 3. 兜底规则（必须保留）
    - service: http_status:404
```

---

## 第 5 步：配置代理（中国网络环境必需）

### 5.1 确认 mihomo 已启动

```bash
systemctl start mihomo
systemctl status mihomo

# 查看 SOCKS5 端口（通常是 7891）
ss -tlnp | grep mihomo
```

### 5.2 安装并配置 tsocks

```bash
apt-get install -y tsocks
```

创建 /etc/tsocks.conf：

```ini
server = 127.0.0.1
server_port = 7891
server_type = 5

# 本地网络不走代理
local = 192.168.0.0/255.255.0.0
local = 10.0.0.0/255.0.0.0
local = 172.16.0.0/255.240.0.0
local = 127.0.0.0/255.0.0.0

reuse = yes
```

### 5.3 测试隧道连接

```bash
killall cloudflared 2>/dev/null
tsocks cloudflared tunnel --edge-ip-version 4 run thinkpad-tunnel
```

如果成功，会看到：
```
CONNECTOR ID                         CREATED              EDGE
e06caf40-xxxx-xxxx-xxxx-xxxx 2026-07-27T07:30:18Z 2xlax01, 1xlax08
```

按 Ctrl+C 停止测试。

---

## 第 6 步：配置 DNS 路由（阿里云）

### 注意

- 保持域名 Nameserver 在阿里云（不要修改为 Cloudflare）
- 在阿里云 DNS 设置中添加 CNAME 记录

### 6.1 登录阿里云域名管理

访问 https://dc.console.aliyun.com/

### 6.2 添加 CNAME 记录

1. 选择域名 newease.cloud
2. 点击 DNS 设置（不是 DNS 修改）
3. 点击添加记录

**添加两条 CNAME 记录：**

**记录 1：**
- 记录类型：CNAME
- 主机记录：@
- 记录值：1c1383ed-a3a6-44ed-979d-e4662cff94fd.cfargotunnel.com
- TTL：10 分钟
- 线路：默认

**记录 2：**
- 记录类型：CNAME
- 主机记录：ssh
- 记录值：1c1383ed-a3a6-44ed-979d-e4662cff94fd.cfargotunnel.com
- TTL：10 分钟
- 线路：默认

> 注意：将 Tunnel ID 替换为你的实际值。

### 6.3 验证 DNS 生效

等待几分钟后，验证：

```bash
dig +short newease.cloud @223.5.5.5
```

期望输出：
```
104.21.24.77
172.67.217.201
```

---

## 第 7 步：配置 systemd 服务

### 7.1 创建服务覆盖配置

创建 /etc/systemd/system/cloudflared.service.d/override.conf：

```ini
[Unit]
After=mihomo.service
Requires=mihomo.service

[Service]
ExecStart=
ExecStart=/usr/bin/tsocks /usr/bin/cloudflared --no-autoupdate --config /etc/cloudflared/config.yml tunnel run
```

### 7.2 启动服务

```bash
systemctl daemon-reload
systemctl enable --now cloudflared
```

---

## 第 8 步：配置 Cloudflare SSL/TLS

### 8.1 登录 Cloudflare 后台

访问 https://dash.cloudflare.com，选择 newease.cloud

### 8.2 配置 SSL 模式

1. 左侧菜单：SSL/TLS
2. 在 Overview 页面，找到 SSL/TLS encryption mode
3. 选择 灵活（Flexible）

### 8.3 开启 HTTP -> HTTPS 重定向

1. 左侧菜单：SSL/TLS -> 边缘证书（Edge Certificates）
2. 找到 始终使用 HTTPS（Always Use HTTPS）
3. 打开开关

---

## 第 9 步：验证服务

### 9.1 验证 cloudflared 服务

```bash
systemctl status cloudflared
cloudflared tunnel info thinkpad-tunnel
journalctl -u cloudflared -f
```

### 9.2 验证 DNS 解析

```bash
dig +short newease.cloud @8.8.8.8
dig +short newease.cloud @223.5.5.5
```

### 9.3 验证 HTTP/HTTPS 访问

```bash
curl -I http://newease.cloud
curl -I https://newease.cloud
curl -I https://newease.cloud/admin
```

期望输出：
```
# HTTP 跳转
HTTP/1.1 301 Moved Permanently
Location: https://newease.cloud/

# HTTPS 访问
HTTP/2 200
server: cloudflare
```

### 9.4 浏览器测试

1. 访问 http://newease.cloud（应跳转到 HTTPS）
2. 访问 https://newease.cloud（应正常显示）
3. 访问 https://newease.cloud/admin（应正常显示，URL 末尾有斜杠）

## 第 10 步：配置 Nginx（可选）

### 10.1 修改 Nginx CSP 配置（允许 Material Symbols 图标）

编辑 deploy/nginx/conf.d/sca-skeleton.conf：

```nginx
# 修改前
add_header Content-Security-Policy "... style-src 'self' 'unsafe-inline'; ... font-src 'self' data:; ..." always;

# 修改后
add_header Content-Security-Policy "... style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; ... font-src 'self' data: https://fonts.gstatic.com; ..." always;
```

### 10.2 修改 /admin 重定向（避免跳转到 :8080）

```nginx
# 修改前
location = /admin {
    return 301 /admin/;
}

# 修改后
location = /admin {
    return 301 https://$host/admin/;
}
```

### 10.3 同步到 105 服务器并 reload

```bash
# 复制配置到 105
scp deploy/nginx/conf.d/sca-skeleton.conf root@105:/data/projects/sca-skeleton/deploy/nginx/conf.d/

# 或复制到 Docker 容器配置
scp deploy/nginx/conf.d/sca-skeleton.conf root@105:/data/docker/containers/nginx/conf.d/

# Reload Nginx
docker exec nginx nginx -s reload
# 或
systemctl reload nginx
```
