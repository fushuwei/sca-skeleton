# Nginx 部署步骤

> 目标服务器：`192.168.1.105`，部署目录：`/data/docker/containers/nginx`
> 本目录文件全部拷贝到上述服务器目录后执行下列命令。本步骤仅安装并配置 Nginx，

## 一. 目录结构说明

```
/data/docker/containers/nginx/
├── docker-compose.yml        # 容器编排
├── conf/
│   └── nginx.conf            # Nginx 主配置
├── conf.d/
│   └── sca-skeleton.conf     # 站点配置（server 块）
├── html/
│   ├── admin/                # ← 放置 admin 打包后的 dist 内容
│   └── portal/               # ← 放置 portal 打包后的 dist 内容
└── logs/                     # Nginx 日志（自动生成）
```

> 路径映射关系：

| 宿主机路径          | 容器内路径              | 用途         |
|---------------------|-------------------------|--------------|
| `./conf/nginx.conf` | `/etc/nginx/nginx.conf` | 主配置       |
| `./conf.d`          | `/etc/nginx/conf.d`     | 站点配置     |
| `./html`            | `/usr/share/nginx/html` | 前端静态资源 |
| `./logs`            | `/var/log/nginx`        | 日志         |

## 二. 部署前端 dist

> Nginx 配置已就绪，但 `html/admin`、`html/portal` 当前为空。需自行打包前端并把 dist 内容拷进去，否则访问会 404。

```bash
# 进入项目根目录
cd /data/projects/sca-skeleton

# 部署后台 dist
pnpm build:admin
mv sca-skeleton-frontend/apps/admin/dist/* /data/docker/containers/nginx/html/admin/

# 部署前台 dist
pnpm build:portal
mv sca-skeleton-frontend/apps/portal/dist/* /data/docker/containers/nginx/html/portal/
```

## 三. 启动 Nginx 容器

```bash
cd /data/docker/containers/nginx

# 拉取镜像 + 后台启动（可能需要 VPN 代理）
docker compose up -d

# 查看容器状态
docker compose ps

# 查看启动日志（排查配置错误）
docker compose logs nginx
```

## 四. 验证配置与连通性

```bash
cd /data/docker/containers/nginx

# 容器内校验 nginx 语法
docker exec nginx nginx -t

# 验证容器 8080 端口映射到宿主机
docker compose ps

# 验证前端页面（应返回 index.html）
curl -I http://192.168.1.105:8080/
curl -I http://192.168.1.105:8080/admin/

# 验证网关反代（先启动 gateway:9999，再测）
curl -I http://192.168.1.105:8080/auth/oauth2/.well-known/oauth-authorization-server
curl -I http://192.168.1.105:8080/api/actuator/health
```

## 五. 常用运维命令

```bash
cd /data/docker/containers/nginx

# 停止
docker compose down

# 重启（修改配置后）
docker compose restart

# 改配置后重新加载（不停机，最常用）
docker exec nginx nginx -s reload

# 语法检查（改完配置先校验）
docker exec nginx nginx -t

# 查看实时访问日志
docker exec nginx tail -f /var/log/nginx/sca-skeleton.access.log

# 查看错误日志
docker exec nginx tail -f /var/log/nginx/sca-skeleton.error.log
```
