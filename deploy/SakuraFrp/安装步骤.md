# SakuraFrp 内网穿透部署步骤

**穿透目标：** Nginx 8080 端口（反代网关 9999，托管 Admin / Portal 前端） **访问地址：** `https://newease.cloud`

## 一、SakuraFrp 配置

### 1.1 获取访问密钥

> 登录 [管理面板](https://www.natfrp.com/user/)，点击「复制访问密钥」。

### 1.2 创建 TCP 隧道

> 参照【创建隧道.png】

### 1.4 进入隧道列表，查看隧道信息

- **隧道 ID：**`28471369`
- **节点域名：**`frp-fit.com`**（鼠标移到节点名称会弹出 tips 显示节点域名）**

## 二、Linux 服务器部署

### 2.1 下载 frpc

> 在 [软件下载](https://www.natfrp.com/tunnel/download) 页面获取 Linux amd64 版 frpc 下载链接：

```bash
wget -O /usr/local/bin/frpc https://nya.globalslb.net/natfrp/client/frpc/0.51.0-sakura-14/frpc_linux_amd64
chmod 755 /usr/local/bin/frpc
frpc -v
```

### 2.2 创建工作目录

```bash
mkdir -p /usr/local/etc/natfrp
```

### 2.3 创建 systemd 服务

```bash
cat > /etc/systemd/system/frpc@.service << 'EOF'
[Unit]
Description=SakuraFrp frpc Service
After=network.target

[Service]
Type=idle
Restart=on-failure
RestartSec=60s
ExecStart=/usr/local/bin/frpc -f %i
WorkingDirectory=/usr/local/etc/natfrp

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
```

### 2.4 启动隧道

> 格式：frpc@<访问密钥>:<隧道ID>

```bash
systemctl start frpc@v7bx44tsklorvz141rmou651sd82csuu:28471369
systemctl enable frpc@v7bx44tsklorvz141rmou651sd82csuu:28471369
```

### 2.5 确认启动成功

```bash
journalctl -u frpc@v7bx44tsklorvz141rmou651sd82csuu:28471369 -n 20
```

正常日志：

```

ubuntu-server frpc[952636]: 请记得为您的域名添加 CNAME 记录到 >>frp-fit.com<<
ubuntu-server frpc[952636]: 2026/07/30 10:10:54 [I] [15/3944888/b9d3] [v7b**suu.thinkpad_sca] 隧道启动成功
```

## 三、阿里云 DNS 配置

> 在 [云解析 DNS 控制台](https://dnsnext.console.aliyun.com/authoritative) 为 `newease.cloud` 添加两条 CNAME 记录：

| 主机记录 | 记录类型 | 记录值        | TTL  |
|----------|----------|---------------|------|
| `@`      | CNAME    | `frp-fit.com` | 默认 |
| `www`    | CNAME    | `frp-fit.com` | 默认 |

> 节点域名以 frpc 启动日志中 `使用 >>xxx<< 连接你的隧道` 为准，不同节点域名不同。

验证生效：

```bash
dig +short newease.cloud @223.5.5.5
```

预期效果：

```
frp-fit.com.
64.49.47.165
```

## 四、SSL 证书

> 自动 HTTPS 默认使用自签证书，浏览器会提示不安全。需替换为受信任证书

### 4.1 申请证书

> 在 [阿里云数字证书管理服务](https://yundun.console.aliyun.com/?p=cas) 申请 **个人测试证书**（域名 `newease.cloud`，DNS
> 验证），下载 **Nginx 格式**，得到 `.pem`（证书）和 `.key`（私钥）。

### 4.2 替换证书

```bash
# 1. 停止当前隧道服务
systemctl stop frpc@v7bx44tsklorvz141rmou651sd82csuu:28471369

# 2. 备份旧的自签证书
mv /usr/local/etc/natfrp/newease.cloud.crt /usr/local/etc/natfrp/newease.cloud.crt.bak
mv /usr/local/etc/natfrp/newease.cloud.key /usr/local/etc/natfrp/newease.cloud.key.bak

# 3. 替换为阿里云下载的正式证书（注意：.pem 文件对应 .crt，.key 文件对应 .key）
cp ~/26339518_newease.cloud_nginx/newease.cloud.pem /usr/local/etc/natfrp/newease.cloud.crt
cp ~/26339518_newease.cloud_nginx/newease.cloud.key /usr/local/etc/natfrp/newease.cloud.key

# 4. 修正权限
chmod 755 /usr/local/etc/natfrp/newease.cloud.crt
chmod 755 /usr/local/etc/natfrp/newease.cloud.key

# 5. 启动隧道服务
systemctl start frpc@v7bx44tsklorvz141rmou651sd82csuu:28471369
```

### 4.3 验证替换是否成功

```bash
openssl x509 -in /usr/local/etc/natfrp/newease.cloud.crt -noout -dates
```

预期输出（说明是阿里云 3 个月免费 DV 证书）：

```
notBefore=Jul 29 00:00:00 2026 GMT
notAfter=Oct 26 23:59:59 2026 GMT
```
